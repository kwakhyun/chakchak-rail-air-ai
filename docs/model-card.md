# 착착 Connection AI 모델 카드

## 목적과 현재 상태

착착 Connection AI는 항공 도착 뒤 공항철도 승강장에 도착할 P50·P90·P95 시간과 후보 열차별 탑승 가능성을 계산한다. 이후 별도의 제약 최적화기가 안전·접근성·예산·환승·예약·관광 운영시간을 통과한 후보 가운데 필수 일정과 지역 체류를 가장 잘 보존하는 여정을 고른다. GPT-5.6 Luna는 계산에 참여하지 않고 확정된 결과를 쉬운 말로 설명한다.

현재 버전은 `2.0.0-sim`이다. 모든 성능 수치는 시뮬레이션 검증 결과이며 실제 승객 운영 성능이 아니다.

| 항목 | 현재 구현 |
|---|---|
| 시간 예측 | P50·P90·P95 Monotonic Quantile GBDT |
| 확률 보정 | P90 여유시간 기반 단조 확률 보정 |
| 트리 수 | 88개 × 3개 시간 헤드 = 264개 |
| 입력 | 항공 지연, 터미널, 도착 시간대, 입국 혼잡, 날씨, 수하물, 이동지원, 큰 짐, 열차까지 남은 시간 |
| 학습 | 터미널·시간대를 층화한 시뮬레이션 2,400건 |
| 확률 보정 | 학습과 분리한 200건 |
| 분리 검증 | 일반·복합위험·저위험·이동지원 각 200건, 총 800건 |
| 참고 분포 | 조건별 1,200회 Monte Carlo |
| 실제 운영 보정 | 미완료 (`realWorldCalibrated: false`) |

`npm run train:model`은 고정 시드로 데이터 생성부터 모델 저장까지 재현한다. 브라우저와 서버는 같은 `src/chakchak-model-data.js` 아티팩트를 사용한다.

## 단조 분위수 모델

각 분위수 모델은 분위수 손실을 직접 줄이는 결정 스텀프 부스팅으로 학습한다. 항공 지연, 입국 혼잡, 날씨, 수하물 지연, 이동지원, 큰 짐, 제2터미널과 혼잡 시간대가 커질 때 예상 도착시간이 빨라지는 방향으로 학습되지 않도록 각 트리의 좌우 값을 제약한다. 시간대의 순환성을 표현하는 사인·코사인 특성은 방향을 고정하지 않는다.

세 분위수는 최종 출력에서 `P50 ≤ P90 ≤ P95`를 보장한다. 학습 범위를 벗어난 입력은 모델 추천권을 중지하고 동일 입력을 1,200회 다시 계산하는 안전 엔진으로 전환한다.

## 네 가지 방법 비교

같은 800개 고정 검증 상황과 같은 독립 관측값을 사용해 아래 네 방법을 비교했다.

1. 단순 시간·정규근사
2. 1,200회 Monte Carlo 참고분포
3. 기존 단조 보정 모델
4. 신규 Monotonic Quantile GBDT

| 방법 | P50 pinball | P50 참고분포 MAE | P90 pinball | P90 참고분포 MAE | P95 pinball | P95 참고분포 MAE |
|---|---:|---:|---:|---:|---:|---:|
| 단순 시간·정규근사 | 16.8592 | 9.970분 | 7.8595 | 15.298분 | 4.7636 | 19.228분 |
| Monte Carlo 참고분포 | 15.9948 | 0분 | 7.1819 | 0분 | 4.3904 | 0분 |
| 기존 단조 보정 | 16.2577 | 4.106분 | 7.1840 | 4.721분 | **4.3462** | **5.191분** |
| 신규 Monotonic Quantile GBDT | **15.9671** | **2.880분** | **7.1461** | **3.798분** | 4.4293 | 5.893분 |

- P50 신규 모델은 기존 보정보다 pinball loss 1.79%, 참고분포 MAE 29.86% 개선됐다.
- P90 신규 모델은 기존 보정보다 pinball loss 0.53%, 참고분포 MAE 19.55% 개선됐다.
- P95 신규 모델은 목표 포함률 95%에 대해 97.25%로 더 보수적이지만, 기존 보정보다 정확도 우위가 없어 추가 개선 대상으로 남긴다.
- 세 신규 시간 헤드의 분위수 교차는 0건이다.

공개 비교 원본은 [`evidence/chakchak-model-v2-comparison.json`](../evidence/chakchak-model-v2-comparison.json)과 [`evidence/chakchak-model-v2-comparison.md`](../evidence/chakchak-model-v2-comparison.md)에 보관한다. 재실행 과정의 로컬 산출물은 Git에서 제외된 `output/audit/`에 생성된다. Monte Carlo는 같은 시뮬레이터의 참고분포이므로 실제 세계의 정답이 아니다.

## 독립 감사

훈련·검증과 다른 시드로 일반·복합위험·저위험·이동지원 각 100개, 총 400개를 다시 만들고 조건별 1,200회 참고 계산과 비교했다.

공개 독립 감사 원본은 [`evidence/chakchak-model-v2-independent.json`](../evidence/chakchak-model-v2-independent.json)에 보관한다. 재실행 산출물은 로컬 `output/audit/`에 생성된다.

## 정식 제약 최적화기

정책 ID는 `chakchak-exact-journey-optimizer-v1`이다. 최대 12개 교통 후보와 8개 지역 일정을 전수 조합해 다음 순서로 판단한다.

### 먼저 지키는 조건

- 모델과 안전 엔진의 탑승 기준
- 확인된 접근성 조건
- 최대 예산
- 최대 환승 횟수
- 예약 가능 여부
- 관광지 운영시간과 최소 체류시간

### 조건을 통과한 뒤 비교하는 순서

1. 필수 일정 보존 수
2. 예약 일정 보존 수
3. 지역 체류시간
4. 목적지 도착시각
5. 가격
6. 환승 횟수

조건을 모두 만족하는 후보가 없으면 가장 위반이 적은 후보와 제외 사유를 반환하며, 확정 가능한 추천으로 표시하지 않는다. 가격·좌석·예약·발권은 공식 채널에서 마지막으로 확인하도록 안내한다.

## 추천 이유와 생성형 AI의 역할

항공 지연, 입국장, 날씨, 수하물, 이동지원, 터미널·도착 시간대, 열차 여유의 일곱 조건이 탑승 가능성을 얼마나 바꾸었는지 더해 설명한다. 반올림 뒤에도 기준값과 기여도 합이 현재 확률과 정확히 맞도록 한다.

GPT-5.6 Luna는 자체 모델이 확정한 숫자와 다음 행동을 한국어·영어·일본어·중국어로 설명한다. 확률, 추천 후보, 제약 결과를 다시 계산하거나 바꿀 수 없다. 응답이 없거나 구조가 맞지 않으면 검증된 기본 안내로 전환한다.

## 자동 검증

`npm test`와 `npm run verify`에서 총 57개 테스트가 통과하며, Playwright가 데스크톱·모바일 핵심 흐름 2개를 별도로 확인한다.

- 자체 모델·단조성·범위 이탈 안전전환·추천 이유 합계
- Monte Carlo 정상·복합지연·재현성·경계조건
- 정식 제약 최적화기의 안전·예산·환승·예약·접근성·운영시간
- 공개데이터 정규화·장애 보완·공식 운행계획 우선순위
- OpenAI 구조화 출력·관련 질문 제한·기본 안내
- 동의 기반 검증 저장소의 무결성·철회·보관 기한
- 실제 요청 크기 제한, 호출 제한과 공개 응답 보안 헤더

## 한계와 다음 검증

- 현재 실제 승객 완료 결과는 0건이며 Brier score, 실제 P50/P90 오차와 실제 탑승 성공률을 주장하지 않는다.
- P95 신규 GBDT는 보수성을 확보했지만 기존 보정보다 정확도 우위가 없다. 현재 P2 실측 파이프라인은 P50/P90만 평가하므로, P95는 저장 필드와 포함률 검증을 추가하기 전까지 시뮬레이션 참고지표로만 공개한다.
- 같은 시뮬레이터가 학습·참고 분포를 만들기 때문에 실제 공항 운영의 모든 변화를 대표하지 못한다.
- 실제 운영 검증은 운영기관 협의, 관리형 데이터베이스, HTTPS, 공식 기록 대조와 별도 개인정보 보호 절차가 갖춰진 뒤 진행한다.
- 좌석, 운임, 발권, 재발권과 연결보호는 코레일·공항철도 공식 채널의 최종 확인 대상이다.
