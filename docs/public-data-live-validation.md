# 공공데이터 실연동 검증 기록

검증일: 2026-08-05 (KST)

## 보안 설정

- 공공데이터 서비스 키는 서버 전용 `.env.local`에만 저장한다.
- `.env.local`은 `.gitignore`에 포함했고 파일 권한을 `600`으로 제한했다.
- 브라우저 코드, API 응답, 로그, 문서에는 키를 기록하지 않는다.

## 융합 API 결과

검증 요청: `KE704`, `2026-08-04 17:05 KST`

| 출처 | 판정 | 확인 결과 |
|---|---|---|
| 인천공항 여객편 운항현황 | `live` | KE704 변경 도착시각, T2, 게이트, 수하물 수취대 |
| 인천공항 입국장 현황 | `live` | 입국장 관측값 12건 |
| 인천공항 공항철도 운행정보 | `live` | 공개 조회기간 운행값 20건 |
| 코레일/TAGO 열차 운행계획 | `fallback` | 코레일 직접 API 어댑터는 활용승인 전 비활성. TAGO는 승인 상태지만 공식 열차·도시코드 조회가 오류 코드 `01`을 반환해, `authoritative: false`인 서버 시연 스냅샷으로 대체 |
| 한국관광공사 TourAPI | `live` | 전주 관광 콘텐츠 8건 |
| 항공기상 METAR | `live` | 인천공항 최신 METAR 관측 전문 |
| Open-Meteo 시간별 기상 | `live` | 요청시각에 대응하는 인천공항 시간별 예보 |

전체 판정은 `hybrid`, 집계는 `live 6 / fallback 1 / demo 0`이다. 여기서 6개 `live`는 data.go.kr 5종과 Open-Meteo 1종이다.

## 오류 판정 원칙

- HTTP 상태가 성공이어도 공공데이터 응답 본문의 `resultCode`를 검사한다.
- 정상 코드(`0`, `00`, `0000`)가 아니면 `live`로 표시하지 않는다.
- 키 없음은 `demo`, 승인·상류·타임아웃 오류는 `fallback`으로 분리한다.
- 좌석 재고, 자동 재발권, 보호 환승, 실시간 KTX 지연은 현재 공개 API로 제공한다고 주장하지 않는다.
- TAGO의 일시적 5xx·타임아웃·호출 제한은 한 번만 재시도한다.
- 인증 전달 오류는 반복 호출하지 않고 5분 동안 회로를 연 뒤 자동 재확인한다.
- 정상값을 받은 적이 있으면 마지막 정상 시간표를 보존하고, 없으면 검증된 시각표로 전환한다.

## 재검증 명령

```bash
npm run verify
npm run dev
curl 'http://127.0.0.1:4173/api/data/fusion?flight=KE704&at=2026-08-04T17%3A05%3A00%2B09%3A00'
```

TAGO만 안전하게 재진단하려면 `node scripts/probe-public-data.mjs`를 실행한다. 이 스크립트는 키 값을 출력하지 않는다.
열차 조회와 도시코드 조회를 함께 확인하려면 `node scripts/probe-tago-diagnostics.mjs`를 실행한다. 공식 HTTPS TAGO 주소만 사용하며 키를 출력하지 않는다.

## OpenAI 실연동

- 가상 여정 정보만 사용한 로컬 제한 환경에서 `/api/ai/concierge` 실연동을 확인했다.
- `gpt-5.6-luna`가 `live` 모드로 구조화 행동 단계 3개를 반환한 기록이 있다.
- 요청에는 이름·연락처·예약번호를 포함하지 않았고 `store: false`와 엄격한 JSON Schema를 적용한다.
- API 장애나 비정상 출력은 검증된 다국어 기본 안내로 자동 전환한다.
- 공개 Sites에서는 영속 호출 제한 바인딩이 있을 때만 유료 AI를 활성화한다. 현재 바인딩이 없으면 키가 설정되어 있어도 기본 안내를 사용해 비용 남용을 차단한다.
